# 首页图库模块与图片详情页

## 需求背景

web 首页顶部导航需要新增 `图库` 入口，用户可以浏览后台审核通过的图片投稿，并点击进入图片详情页查看完整图片内容。

## 实现概要

- 顶部导航在 `购物` 右侧新增 `图库`，跳转 `/gallery`。
- 新增公开图库列表页 `/gallery`，分页展示 `content_type=1` 且 `status=3` 的图片稿件。
- 新增公开图片详情页 `/gallery/:imageId`，展示标题、作者、发布时间、简介、标签和全部图片。
- 后端新增 `/web/gallery/loadImageList` 和 `/web/gallery/getImageInfo`，数据源复用 `video_info_post` 与 `video_info_file_post`。

## 接口变化

- `GET/POST /web/gallery/loadImageList`
  - 参数：`pageNo`、`pageSize`
  - 返回：分页图片稿件列表。
- `GET/POST /web/gallery/getImageInfo`
  - 参数：`imageId`
  - 返回：图片稿件详情与图片附件列表。

## 数据变化

- 不新增数据库字段。
- 不写入 `video_info`，不接入推荐流、搜索索引、动态流、评论或互动链路。
- 依赖此前已执行的 `video_info_post.content_type` SQL。

## 验证方式

- 后端运行 `go test ./...`。
- web 前端运行 `npm run build`。
- 手动验证顶部导航、图库列表、图片详情、多图展示和空状态。

## 遗留风险

- 图片详情页当前只负责展示内容，不支持评论、点赞、收藏、投币。
- 图片稿件不会进入视频搜索和推荐体系，后续如需公开搜索需要单独设计图片索引。
