# 图库空条件搜索返回全部结果

## 需求背景

图库顶部搜索栏支持“文搜图 / 图搜图”切换。用户在文搜图模式下清空关键词后点击搜索按钮，需要回到图库全部列表，而不是保持空操作。

## 实现概要

- 在 `echo-space-frontend-web` 的顶部搜索栏中，图库上下文下的文搜图按钮点击逻辑做了兜底。
- 当关键词为空或只包含空白字符时，直接跳转回 `/gallery`，恢复普通图库分页列表。
- 图搜图逻辑保持不变，仍然优先选择图片文件并发起向量检索。

## 核心改动文件

- `src/views/layout/LayoutHeader.vue`

## 接口变化

- 无后端接口变化。

## 验证方式

- 在图库页切换到“文搜图”。
- 清空输入框后点击搜索按钮。
- 页面应回到全部图库列表。

## 遗留风险

- 当前行为依赖前端路由切换恢复列表；如果未来图库搜索页交互改造，需要同步检查这里的回退逻辑。
